# 🐝 KVIC Bee Mitra - Smart Beekeeper Telemetry Portal
> **National Honey Mission • Khadi & Village Industries Commission (KVIC)**

An IoT-enabled smart apiculture web application developed to modernize beekeeping practices under the Khadi & Village Industries Commission (KVIC) National Honey Mission. Built with a clean, mobile-first approach, it empowers beekeepers and rural farmers with real-time telemetry, automated hive health monitoring, disease diagnosis, and honey harvest yield forecasting.

---

## 🌟 Key Features

- **📊 Real-Time Hive Health Telemetry**: Live temperature & moisture monitoring with optimal range indicators (33°C–36°C, 50%–65% RH), acoustics frequency (Hz), and color-coded health spectrum gauge.
- **📦 Smart Hive Box Management**: Manage multiple hive boxes with tracked field initiation dates, one-tap "Hive Boxes" selector modal, and auto-sorting of recently viewed boxes.
- **🍯 Honey Harvest & Yield Forecast**: Real-time harvest day countdown, expected honey yield (kg), estimated market valuation (₹), and dynamic animated honey pot graphic.
- **🚨 Disease & Pest Early Warning**: Diagnostic alerts for Varroa Destructor Mites, fungal infections, and heatwaves with certified scientific treatment protocols.
- **🗣️ Multilingual & Voice Assistant**: Full support for 6 regional Indian languages (**Hindi**, **English**, **Tamil**, **Telugu**, **Kannada**, and **Malayalam**) with native speech readout.
- **☁️ Firebase Cloud Sync**: Real-time persistence and synchronization powered by Firebase Firestore and Analytics.
- **📱 Clean Mobile Interface**: App-like layout without native scrollbar distractions, thumb-friendly touch targets, and beekeeper profile card.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3, Modern ES6+ JavaScript
- **Cloud & Database**: Google Firebase (Firestore Database & Analytics)
- **Audio API**: Web Speech Synthesis API (`SpeechSynthesis`)
- **Server**: Node.js (`serve` / npm)

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed.

### Setup & Run
```bash
git clone https://github.com/iamchideshv/KVIC-BEEKEEPER-APP.git
cd KVIC-BEEKEEPER-APP
npm install
npm start
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
